# Event Ticket Booking System

A responsive and user-friendly **Event Ticket Booking System** developed using **HTML, CSS, and JavaScript**. The project allows users to explore upcoming events and submit ticket booking details through an interactive booking interface.

## Project Overview

This project was developed as part of my Front-End Development Internship. It demonstrates my practical understanding of creating responsive web pages, designing user interfaces, and implementing client-side form validation using JavaScript.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Features

* Responsive Event Ticket Booking interface
* Upcoming event cards for:

  * Movie Night
  * Music Concert
  * Cricket Match
* Event details including date, time, price, and location
* Interactive "Book Ticket" functionality
* Booking form with name, email, event, and ticket count fields
* JavaScript form validation
* Smooth navigation between Home, Events, Booking, and Contact sections
* Hover effects and responsive layout
* Mobile-friendly design using CSS Media Queries
